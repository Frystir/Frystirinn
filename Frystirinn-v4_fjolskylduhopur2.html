Athugar tengingu…
Hvernig á að tengja Supabase:
1. Farðu á supabase.com/dashboard
2. Búðu til nýtt verkefni (New project)
3. Í SQL Editor: búðu til freezer_data töfluna með user_id dálki og RLS reglum
4. Farðu í Authentication → Providers og staðfestu að Email sé virkt
5. Farðu í Settings → API
6. Afritaðu Project URL og anon public key
7. Opnaðu þennan HTML skrá í textaritli
8. Fylltu út SUPABASE_URL og SUPABASE_ANON_KEY efst í skriptunni
9. Vistaðu skrána og settu hana upp aftur
